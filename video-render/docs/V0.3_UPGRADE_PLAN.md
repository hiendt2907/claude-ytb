# v0.3 Upgrade Plan

Muc tieu v0.3: nang video-render tu auto-assembler MVP thanh tool render hang loat de dung hon cho KOL/KOC/affiliate, uu tien trai nghiem nguoi dung truoc, sau do moi toi uu ky thuat. User khong bi ep vao mot khuon workflow duy nhat: app tu dong lam tot khi user muon nhanh, nhung van cho user tu chon clip bang format `1.1, 2.1, 3.2` khi can kiem soat chinh xac.

Baseline da luu: tag `v0.2.0`.

Trang thai: da release `0.3.0` ngay 2026-07-08 sau khi full tests, browser smoke, va ffmpeg smoke render pass. Ke hoach nay duoc giu lai lam record cho scope v0.3 va lam checklist tham chieu cho cac version tiep theo.

## 1. Nguyen Tac San Pham

- Mac dinh la "App tu chon": user chon nguyen lieu, voice, output, bam xem thu/render.
- Khong bat user hieu scene/duration/profile/seed/manual plan truoc khi dung duoc app.
- Van giu "Tu chon clip" cho user co chu dich: nhap nhanh `1.1, 2.1, 3.2`, moi dong la mot video.
- Input khong hoan hao thi app nen phan tich, giai thich, va goi y cach sua truoc khi chan render.
- UI noi bang ngon ngu ket qua: muot hon, nhanh hon, giu canh lau hon, doi doan khac, khop voice hon.
- Khong lam timeline editor kieu CapCut; tool nay van la batch auto-editor/render-only.

## 2. Scope v0.3

### 2.1 Flexible Clip Control

Da bat dau trong `Unreleased`:
- Manual parser chap nhan ca format co nhan `video 1: ...` va format ngan `1.1, 2.1, 3.2`.
- Them API preview/validate manual plan truoc khi render.
- UI doi wording thanh `App tu chon` / `Tu chon clip`, co nut `Kiem tra danh sach`.
- Scan scenes tra clip ref -> ten file de user biet `1.1` la clip nao.
- Them nut "Tao mau tu clip dang co" de app sinh skeleton plan cho user sua.

Con lai:
- Manual mode van di qua Smart Trim 2 mac dinh; sau nay moi them advanced "Dung dung doan goc" neu can.

### 2.2 Smart Trim 2

Muc tieu: tu chon doan dep tot hon Smart Trim MVP, khop nhu cau video thay vi chi lay best segment dau tien.

Can lam:
- Chon nhieu `ClipSegment` khong overlap trong cung mot clip khi can keo dai canh.
- Fit tong duration sat voice/scene target hon, khong lam output qua ngan.
- Cham diem segment theo:
  - freeze/black penalty;
  - edge/rung dau-cuoi clip penalty;
  - duration fit;
  - diversity de tranh chon cac doan qua gan nhau;
  - profile intent: nhanh, muot, review, catalog.
- Neu khong du doan sach, fallback ro rang: dung doan it xau nhat va log canh bao de UI noi de hieu.

Trang thai:
- Da co greedy selector chon nhieu segment khong overlap trong cung clip.
- Con lai: scoring motion/anh sang on dinh, fallback warning ro hon, va pacing intent.

Files chinh:
- `src/ytb_pipeline/assembler/smart_trim.py`
- `src/ytb_pipeline/webui/jobs.py`
- `tests/test_smart_trim.py`
- `tests/test_webui_jobs.py`

### 2.3 Pacing Theo Voice

Muc tieu: app giup video khop voice hon ma khong bat user canh tung tham so.

Can lam:
- Them layer pacing planner giua duration strategy va Smart Trim.
- Map UI intent de hieu:
  - `Theo voice`: uu tien khop giọng đọc.
  - `Nhanh gon`: cut ngan hon, it giu canh dai.
  - `Muon muot`: transition/motion mem hon, it cut gat.
  - `Giu nhieu canh goc`: it trim manh.
- Neu `voice_silence` tach sai so canh, UI goi y fallback sang app tu canh thoi luong thay vi chi bao loi ky thuat.

Files chinh:
- `src/ytb_pipeline/assembler/duration.py`
- `src/ytb_pipeline/assembler/smart_trim.py`
- `src/ytb_pipeline/webui/templates/index.html`

### 2.4 Quality Gate Va Retry Dung Video Loi

Muc tieu: render xong user biet video nao dung duoc, video nao can render lai, va render lai dung video loi.

Can lam:
- Luu render plan metadata cho tung output:
  - assignment;
  - selected segments;
  - profile;
  - duration mode/intent;
  - output path;
  - quality result.
- Them quality checks:
  - audio/video duration mismatch;
  - output qua ngan/qua dai so voi voice;
  - canh bi loop qua nhieu;
  - segment bi trim qua ngan;
  - freeze/black hien co giu nguyen.
- Them profile `smooth_retry` trong `profiles.py`.
- Nut retry tren tung video loi dung lai assignment/segments cu, khong sinh bien the moi.

Trang thai:
- Da luu render plan metadata serializable trong job.
- Da them quality warning khi audio/video duration lech nhau.
- Da them profile `smooth_retry`.
- Da co endpoint/flow retry tung output dung lai assignment/segments cu.

Files chinh:
- `src/ytb_pipeline/webui/jobs.py`
- `src/ytb_pipeline/webui/quality.py`
- `src/ytb_pipeline/assembler/profiles.py`
- `src/ytb_pipeline/assembler/render.py`
- `src/ytb_pipeline/webui/templates/index.html`

### 2.5 Preview Dang Tin Hon

Muc tieu: preview giup user quyet dinh truoc khi render full.

Can lam:
- Preview khong chi lay 4 canh dau; voi video dai, lay mau dau + giua + cuoi.
- Hien ket qua quality preview bang ngon ngu de hieu.
- Sau preview co nut chinh nhanh:

  - Nhanh hon;
  - It zoom hon;
  - Giu canh lau hon;

- Cac nut nay doi intent/config ben duoi, khong bat user sua tham so ky thuat.

Trang thai:
- Da lay mau preview trai deu dau/giua/cuoi.
- Da co quick adjustment buttons sau preview.

Files chinh:
- `src/ytb_pipeline/webui/jobs.py`
- `src/ytb_pipeline/webui/templates/index.html`
- `tests/test_webui_jobs.py`
- `tests/test_webui_app.py`
